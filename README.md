An original turn-based card duel for the [make.fun best card game bounty](https://make.fun/c/best-card-game-20261122-1826).

Two ember-courts clash on a felt table: summon guardians, spend ember mana,
exploit the elemental wheel (Flame > Thorn > Tide > Flame), and burn the
rival warden's 30 life to ash before yours is spent.

Play it: serve `game/` with any static server and open `game/index.html`
in a desktop browser. No network, no build step.
